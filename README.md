# 外郎売アクセント稽古帳

外郎売の口上全文（6つの段に分けて表示、ふりがな付き）で、苦手な語のアクセントを練習するためのページです。本文とふりがなは文化ネット「外郎売」の練習用台本に合わせています。

- 指導する人がお手本（単語・句・手がかり語）をその場で吹き込む
- 下がる場所をタップで付け、ハミングで形だけを聞く
- 段階練習（メロディだけ → 手がかり語から → ゆっくり → ふつう → 句の中で）
- 自分の声を録って、お手本と声の高さの線を見比べる

録音はそれぞれの端末のブラウザの中に保存され、どこにも送信されません。
端末を移すときは「書き出す」「読み込む」を使います。

## 共有お手本版（/share/）

吹き込む人が上げたお手本を、練習する人がそれぞれの端末で聞ける版です。

- お手本の音声と形は、公開リポジトリ `nonnothing/uirou-keiko-audio` に置かれ、誰でも聞けます
- 上げられるのは、そのリポジトリだけに書き込める鍵（fine-grained token）を自分の端末に入れた人だけです
- 練習する人の自分の声は、その端末の中だけに保存されます
